### 1. 문제 설명

문자열 `my_string`, `overwrite_string`과 정수 `s`가 주어집니다. 문자열 `my_string`의 인덱스 `s`부터 `overwrite_string`의 길이만큼을 문자열 `overwrite_string`으로 바꾼 문자열을 return 하는 solution 함수를 작성해 주세요.

### 2. 처음 풀이 내용

```jsx
function solution(my_string, overwrite_string, s) {
  let answer = my_string.substr(0, s) + overwrite_string;

  if (answer.length - s >= overwrite_string.length) {
    const extraIndex = s + overwrite_string.length;
    answer += my_string.substr(extraIndex, my_string.length);
  }

  return answer;
}
```

### 3. 배운 내용
- `substring`
  - 시작 인덱스와 종료 인덱스를 사용합니다.
  - 종료 인덱스를 생략하면 끝까지 가져옵니다.
  - 음수 인덱스를 허용하지 않음
  - 시작 인덱스와 종료 인덱스 순서는 자동으로 조정됩니다. (즉, 작은 값이 시작 인덱스가 됨)
- `slice`
  - **시작 인덱스**와 종료 인덱스(포함되지 않음)를 사용합니다.
  - 종료 인덱스를 생략하면 끝까지 가져옵니다.
  - 음수 인덱스를 사용하여 문자열 끝에서부터 계산 가능합니다
 
- `substring`과 `slice`의 두 가지 함수 비슷하게 동작하기 때문에 성능이 아닌 기능적 차이와 가독성을 선택으로 합니다.
    - `substring` 의 경우 음수 인덱스를 사용하지 않고, 인덱스 순서를 자동으로 조정을 원할 때
    - `slice` 의 경우 음수 인덱스 지원, 배열에서도 지원하기에 유연성이 뛰어남

### 4. 개선할 점

- 불필요한 if 문은 생략

```jsx
function solution(my_string, overwrite_string, s) {
  return `${my_string.slice(0, s)}${overwrite_string}${my_string.slice(s + overwrite_string)}`;
}
```
