### 1. 문제 설명

길이가 같은 두 문자열 `str1`과 `str2`가 주어집니다.

두 문자열의 각 문자가 앞에서부터 서로 번갈아가면서 한 번씩 등장하는 문자열을 만들어 return 하는 solution 함수를 완성해 주세요.

### 2. 처음 풀이 내용

```jsx
function solution(str1, str2) {
  let result = "";
  for (let i = 0; i < str1.length; i++) result += str1[i] + str2[i];

  return result;
}
```

### 3. 배운 내용

<aside>
💡

- 불변한 타입: `String`, `Number`, `Boolean`, `null`, `undefined`
- 가변한 타입 (Mutable): `Object`, `Array`, `Map`, `Set`

문자열은 불변한 타입으로 누적연산 필요 시, `Map + join(””)` 을 사용하는 것이 메모리에 효과적

</aside>

- `map`
  [Array.prototype.map() - JavaScript | MDN](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array/map)
  - map은 특정 방식으로 변환하여 새로운 배열을 생성
  - 만약 해당 문제로 map을 사용한다면, 새로운 배열을 합치는 연산 비용이 발생합니다
  - 배열에 데이터를 저장한 뒤 한 번의 병합 작업만 수행하므로, O(n)의 메모리 비용이 발생
- `reduce`
  [Array.prototype.reduce() - JavaScript | MDN](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array/reduce)
  - 배열을 생성하지 않습니다.
  - `reduce`는 문자열을 누적 연산 통해 직접 값을 반환합니다.
  - 하지만, 매번 누적 시 문자열 전체를 다시 복사해야 하므로, **O(n²)에 가까운 메모리 복사 비용이 발생**합니다.

### 4. 개선할 점

- 문자열 누적 (`+=`) 은 매번 새로운 문자열을 생성하기 때문에 성능 저하의 원인이 될 수 있습니다.
- 문자열은 불변(immutable)이므로 `+=` 연산은 기존 문자열을 복사하고, 새로운 문자열을 생성합니다.

```jsx
function solution(str1, str2) {
  return [...str1].map((x, index) => x + str2[index]).join("");
}
```
